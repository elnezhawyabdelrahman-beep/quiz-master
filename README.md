# Quiz Master

تطبيق مسابقات وأسئلة ثقافية باللغة العربية، مبني كتطبيق ويب تقدمي (PWA).

## المزايا في النسخة التأسيسية
- تصنيفات متنوعة وأسئلة اختيار من متعدد مع شرح ومصدر مختصر.
- لاعب واحد، منافسة ضد الكمبيوتر، ولاعبون محليون على نفس الجهاز.
- ملفات لاعبين مستقلة ونقاط خبرة ومستويات وسجل جولات.
- إعداد عدد الأسئلة والصعوبة المتاحة والمؤقت.
- خلط الأسئلة والاختيارات وتقليل تكرار الأسئلة التي شوهدت مؤخرًا.
- حفظ الجولة النشطة محليًا واستكمالها.
- تصدير واستيراد نسخة احتياطية.
- تصميم متجاوب، مع دعم التثبيت والعمل دون اتصال بعد أول تحميل.

## ملاحظة مهمة عن بنك الأسئلة
هذه نسخة تأسيسية تحتوي على مجموعة أولية من الأسئلة. لا تدّعي وجود مئات الأسئلة المراجعة في كل تصنيف بعد؛ سيتم توسيع البنك على دفعات مع مراجعة الحقائق والمصادر قبل نشرها.

## النشر على GitHub Pages
1. افتح Settings ثم Pages.
2. من Build and deployment اختر Deploy from a branch.
3. اختر الفرع main والمجلد /(root) ثم Save.

بعد اكتمال النشر، افتح الموقع مرة واحدة عبر HTTPS ثم استخدم خيار التثبيت من المتصفح.
